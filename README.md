# Putt Break Reader

iPhoneをグリーンに置いて傾斜を測り、パッティングの打ち出し方向と曲がり幅を表示するWebアプリです。

## 使い方
1. iPhoneのSafariでアプリのURL（HTTPS）を開く
2. 「START」をタップして、センサーの使用を許可する
3. 画面を上にしてグリーンに置き、端末の上端をカップに向ける
4. 下のボタンでカップまでの距離とグリーンの速さ（Stimp）を合わせる
5. オレンジの線の方向に打ち出す

- **ZERO**：平らな場所でタップすると、その面を0%に補正（長押しでリセット）
- **HOLD**：表示を固定（スマホを拾い上げて画面を見るとき用）
- **FT / M**：距離の単位を切り替え

## 2つのタブ
画面の上のボタンで切り替えます。距離と Stimp は両方のタブで共通です。
- **傾斜を測る**：センサーで傾斜を測り、打ち出し方向と曲がり幅を表示
- **振り幅を計算**：距離と上り下りからテークバックの幅とテンポを表示
